🏧 ATM Simulation Project (Python + Streamlit)

📌 Project Overview
This is a beginner-friendly ATM Simulation System built using Python.

The project was implemented in two different approaches:
1️⃣ Loop-based (menu-driven program)
2️⃣ Function-based (modular and structured approach)

Additionally, a simple web interface was created using Streamlit to convert the console-based application into an interactive web app.

🚀 Features
🔐 PIN Authentication
💰 Balance Inquiry
➕ Deposit Money
➖ Withdraw Money
📜 Transaction History
⚠ Input Validation
🌐 Web Interface using Streamlit
🧠 Python Concepts Used

Loops (while loop for menu handling)
Functions (modular programming)
Conditional Statements (if-else logic)
Basic Exception Handling
List handling (for transaction history)
User input handling
This project is designed based on common interview scenarios like ATM or banking systems.

🖥️ Technologies Used
